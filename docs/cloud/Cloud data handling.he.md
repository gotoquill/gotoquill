# טיפול במידע ב-Cloud

עודכן לאחרונה: 23 בנובמבר 2026 (שעון ישראל). אינו ייעוץ משפטי.

דף זה זמין גם [באנגלית](Cloud%20data%20handling.md). אם יש הבדל בין הנוסחים, יחול הנוסח המיטיב עמכם.

דף זה מסביר בשפה פשוטה כיצד Gotoquill Cloud מטפל במידע. הוא אינו מחליף את [מדיניות הפרטיות](https://gotoquill.com/privacy/he/) או את [תנאי השימוש](https://gotoquill.com/terms/he/). Gotoquill Local פועל במחשב שלכם ברישיון Apache 2.0. Gotoquill Cloud הוא שירות מתארח נפרד שמפעיל שי לוי בישראל.

## איזה מידע Cloud שומר והיכן

Cloud מעבד ושומר מידע בתשתיות Cloudflare, באמצעות Workers, KV ו-Durable Objects. אין בכך התחייבות לאחסון בישראל בלבד. כאשר Cloud יוצר תוצר לא מקוון של Muse, תוכן ה-PDF נשלח ל-Cloudflare Browser Rendering.

- קובצי PDF מקוריים של בקשות ממתינות, מטעני חתימה מוצפנים והמפתחות הנדרשים לעיבוד תשובות החתימה ולהטבעת חתימות ב-PDF בשרת.
- רשומות בקשה: שיוך לחשבון, שם המסמך והגיבוב שלו, מיקומי חתימות, שם החותם אם נמסר, נוסח הסכמה, חותמות זמן, מצב הבקשה, הודעות, נתוני הוכחה וסיבת סירוב אם נמסרה. בקשות שהושלמו עשויות לכלול את ה-PDF החתום ואת נתוני החתימה.
- נתוני חשבון ואימות: מזהי חשבון הנגזרים מספק ההתחברות, שם ודוא"ל אם נמסרו, זמני יצירה ופעילות אחרונה, לקוחות מחוברים, גרסת התנאים שאושרה ומועד האישור, הפעלות דפדפן, נתוני לקוחות OAuth, גיבובים של פרטי גישה, משפחות אסימוני רענון, הרשאות הסכמה ורשומות ביטול גישה. ההתחברות משתמשת גם בקודי הרשאה ובנתוני מצב זמניים של דוא"ל וספקי התחברות.

## הצפנה וגישה

**Cloud אינו מוצפן מקצה לקצה ואינו שירות בידע אפס (zero-knowledge).** הוא שומר מסמכים ממתינים ומפתחות חתימה ומטביע חתימות ב-PDF בשרת. הצפנה בקישור חתימה אינה מונעת מהמפעיל לגשת למסמכים ולמפתחות השמורים כל עוד הם קיימים.

המפעיל יכול לגשת למידע השמור לצורך הפעלת השירות וטיפול בבקשות תמיכה או מחיקה. Cloudflare מעבדת אותו כספקית התשתית. החשבון המחובר וחיבורי העוזרים המורשים שלו יכולים לגשת לבקשות שלהם. כל מי שמחזיק בקישור חתימה או בקובץ חתימה לא מקוון יכול לפתוח את המסמך ולפעול כחותם כל עוד הבקשה ממתינה; עצם ההחזקה אינה מאמתת זהות. גם קישורי תצוגה מקדימה והורדה מקנים גישה לתוצר שאליו הם מפנים כל עוד הם תקפים. שתפו אותם רק עם הנמענים המיועדים.

שירותי הצ'אט המארחים מקבלים את הקלט והפלט של הכלים, קובצי PDF, תצוגות מקדימות או תוצרי חתימה שמועברים אליהם. עותקים בצ'אטים, בהורדות או בקבצים לא מקוונים כפופים לאופן הטיפול ולתקופות השמירה של המחזיקים בהם. מחיקת העותק ב-Cloud אינה מוחקת עותקים אלה.

## תקופות שמירה

אלה התקופות ש-Cloud משתמש בהן. המפעיל יכול להגדיר את ברירת המחדל ואת התקופה המרבית לבקשות ממתינות. הקוד אוכף מינימום של שעה לבקשה ממתינה ומקסימום של 30 ימים לבקשה שהסתיימה.

| מידע | תקופת שמירה |
| --- | --- |
| בקשה ממתינה, PDF מקורי ותיבת הודעות הבקשה | ברירת מחדל של 7 ימים; מינימום שעה; ברירת המחדל לתקרה המוגדרת היא 14 ימים. |
| רשומת בקשה שהסתיימה ו-PDF חתום אם קיים | ברירת מחדל של 30 ימים לאחר השלמה, סירוב או ביטול. המפעיל יכול להגדיר תקופה קצרה יותר. |
| רשומות חשבון ואינדקס משתמשים | ללא תפוגה אוטומטית. לבקשת מחיקה פנו אל privacy@gotoquill.com. |
| הפעלת דפדפן | חלון של 7 ימים ללא פעילות, שמתחדש רק כשאתם חוזרים למסך החיבור או ההסכמה של Cloud, עם תקרה מוחלטת של 90 ימים ממועד ההתחברות. פעילות כללית, שימוש בדף החתימה ושימוש בעוזר אינם מחדשים את החלון הזה. |
| לקוחות OAuth רשומים | 90 ימים, עם הארכה כשהרישום מתרענן בהצלחה. |
| הרשאות הסכמה שנשמרו | 90 ימים לאחר האישור. שימוש חוזר בהרשאה שנשמרה אינו מאריך את תוקפה. |
| פרטי גישה של OAuth | שעה. |
| משפחת אסימוני רענון של OAuth | 90 ימים ללא פעילות, עם חידוש בעת החלפת אסימון ותקרה של 180 ימים ממועד היצירה. במשפחות ישנות ללא מועד יצירה, מועד התפוגה הקיים נשאר התקרה. |
| קודי הרשאה | 5 דקות. |
| תהליכי התחברות והסכמה ונתוני מצב של ספק ודוא"ל | עד 10 דקות, בכפוף לתפוגת תהליך ההתחברות. |

כשבקשה עוברת למצב סופי, הרשומה הנשמרת מסירה את מפתחות החתימה ואת פרטי הגישה להעלאה. לאחר מכן Cloud מנסה למחוק את ה-PDF המקורי, את התוצר הלא מקוון ואת תיבות הבקשה והתשובה. אם המחיקה מהאחסון נכשלת, פעולת כתיבה מורשית מאוחרת יותר יכולה לנסות שוב; מועד התפוגה המקורי באחסון הוא הגיבוי. הרשומה הסופית וה-PDF החתום, אם קיים, נשארים לתקופת השמירה הנפרדת שלהם. הורדה אינה מוחקת מידע ואינה מאריכה תקופה זו.

Durable Objects בודקים תפוגה בקריאה ומשתמשים בהתראות מתוזמנות למחיקה. מחיקה ב-KV מתעדכנת בהדרגה בין עותקי האחסון. מועדים אלה אינם מבטיחים את מועד המחיקה הפיזית מגיבויים או מיומנים של ספקים. סמני ביטול גישה לחשבון עשויים להישאר כדי למנוע חזרה של גישה שבוטלה. יומני ספקים, דואר תמיכה ועותקים שיוצאו לצורכי תפעול מחייבים טיפול נפרד; תפוגת המסמך אינה מוחקת אותם. ראו את [טבלת תקופות השמירה במדיניות הפרטיות](https://gotoquill.com/privacy/he/) לגבי אירועי אבטחה מובנים, אנליטיקה, משוב ויומני הניטור של Cloudflare ויומני ספקים אחרים. יומני Cloudflare Workers של Cloud נשמרים 7 ימים. יומנים אלה ויומני ספקים אחרים עשויים להישמר מעבר לתקופות שמירת המסמכים באפליקציה.

## ביטול ומחיקה

בקשו מהעוזר המחובר לבטל בקשה ממתינה כדי לעצור את החתימה ולהתחיל את הניקוי המתואר לעיל. הביטול משאיר רשומה סופית לתקופת השמירה של בקשות שהסתיימו; הוא אינו מחיקה מלאה ומיידית. הסרת Gotoquill משירות צ'אט מפסיקה את השימוש דרך אותו שירות, אך אינה מבטלת כשלעצמה אישורי גישה ש-Gotoquill כבר הנפיק ואינה מוחקת מידע שנשמר. לביטול גישה או למחיקת החשבון, כתבו אל privacy@gotoquill.com. דף זה אינו מבטיח מחיקת חשבון בשירות עצמי.

לבקשות מחיקת חשבון או מידע אחר, כתבו אל [privacy@gotoquill.com](mailto:privacy@gotoquill.com). למפעיל יש תהליך נפרד למחיקת חשבון. אל תשלחו קישורי חתימה, סיסמאות או תוכן מסמכים בדוא"ל הראשוני. שמרו עותקים משלכם של קובצי PDF חתומים לפני תפוגתם, ופנו בנפרד לשירותי הצ'אט או לנמענים אחרים לגבי מחיקת העותקים שבידיהם.

עותק מוגבל של מידע שנשמר לצורך בקשת עיון יישמר בנפרד עד למענה ולמתן הזדמנות סבירה לעיין בו. שמירה זו אינה מאריכה את תוקף קישורי החתימה או אישורי הגישה.
