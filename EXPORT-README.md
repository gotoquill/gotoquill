# Reviewed Local source export

This tree comes from a closed, reviewed file allowlist at a pinned Git commit. The private exporter resolves `--ref` (default `main`) once and reads both the manifest and file bytes from that commit, including reviewed public overrides. Uncommitted source edits are not exported. The hosted implementation remains private.

The exporter supports `--dest` and `--dry-run`. It incrementally adds or updates allowlisted files, preserves destination Git history, and never initializes a repository, creates a commit, or configures a remote. For withdrawals, supply `--previous-ref` with the prior source commit. That allows deletion only of previously allowlisted files and checks existing bytes against that baseline. Record source commits in the private release ledger, not public history. Without a previous ref, unexpected files cause refusal. A dirty Git checkout, unexpected files (including ignored caches), symlinks, and unsafe paths also cause refusal. Only documented empty workspace mounts are exempt. Run with no concurrent destination writers. Per-file writes are atomic; a filesystem failure can leave a partial sync for review and recovery.

An empty directory is a valid first destination. An existing reviewed tree is updated in place. Review the dry-run list and diff before accepting each sync. Integrate public contributions into the authoritative source before exporting again. Keep any destination commits and remote setup as separate, explicitly authorized actions. Initial public history must be fresh and must not import private commits, tags, or branches.

Install from this checkout with `python -m pip install -e '.[dev]'` and run `python -m pytest -q`. Public CI runs Local pytest manually on Python 3.10-3.13; it does not build packages. Run the published package with `uvx gotoquill mcp`. Build public wheels and source archives only from this reviewed public tree and inspect their contents. The private package configuration includes the whole `gotoquill/` directory, including the private Cloud skeleton when built from private source.
