## Offline PDF browser libraries

- **pdf-lib 1.17.1**, MIT. Official npm release: https://registry.npmjs.org/pdf-lib/-/pdf-lib-1.17.1.tgz
  (`dist/pdf-lib.min.js`, `LICENSE.md`). Vendored as `web/vendor/pdf-lib.min.js` and
  `web/vendor/LICENSE.pdf-lib`. Upstream: https://github.com/Hopding/pdf-lib/tree/v1.17.1.
- **PDF.js / pdfjs-dist 4.10.38**, Apache-2.0. Official Mozilla npm release:
  https://registry.npmjs.org/pdfjs-dist/-/pdfjs-dist-4.10.38.tgz
  (`build/pdf.min.mjs`, `build/pdf.worker.min.mjs`, `LICENSE`). Vendored with
  `web/vendor/LICENSE.pdfjs`. Upstream: https://github.com/mozilla/pdf.js/tree/v4.10.38.

The official minified artifacts are unmodified. SHA-256 hashes and source URLs
are recorded in `web/vendor/pdf-sources.json`. File-mode HTML embeds these builds
and uses blob URLs, including a blob PDF.js worker for `file://`. There is no CDN
or runtime network dependency. PDF.js evaluation is disabled; system fonts are
used when a PDF does not embed its own fonts. Preserve all bundled licenses.

## Native and copyleft components

Certifi's CA bundle uses MPL-2.0. Preserve its license and applicable covered-source availability when redistributing. pypdfium2 wraps PDFium and distributes native libraries with additional notices; preserve all wheel license files. The relay's Wrangler development toolchain can include Sharp and LGPL libvips. Redistributed native binaries or development images must preserve the accompanying notices and satisfy their source and replacement obligations. Consult the licenses in each resolved artifact before distributing it.
